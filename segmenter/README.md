# Segmenter
This is the segmenter app used to verify our Geographic Atrophy for clinicians. It is built as a stand alone app.  You need the model checkpoint (not included here) and this will run.  I am currently working on defaults so that there is a setup instead of having to have each person edit the file for their location.

Venv setup is in pyproject.toml.
